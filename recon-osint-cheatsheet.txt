## Nmap

```
sudo nmap -sS -sV -O 127.0.0.1
nmap -sn 10.0.2.0/24
nmap 8.8.8.8
nmap -p 22,80,443,587 <target>
sudo nmap -sS 192.168.56.10
sudo nmap -O 10.49.154.234
sudo nmap -A 10.49.154.234
```
⚠️ Original had `nmap -p- 22,80,443,587` — invalid. `-p-` already means "all 65535 ports," so it can't be followed by a port list, and no target was specified. Fixed to `nmap -p 22,80,443,587 <target>` (use `-p-` alone if you actually want every port scanned).

## Sysmon

Path: EventViewer → Applications → Microsoft → Windows → Sysmon → Operational

Config file (`sysmon-config.xml`):
```xml
<Sysmon schemaversion="4.90">
  <EventFiltering>
    <NetworkConnect onmatch="exclude" />
    <FileCreate onmatch="exclude" />
    <RegistryEvent onmatch="exclude" />
    <DnsQuery onmatch="exclude" />
    <FileDelete onmatch="exclude" />
    <FileDeleteDetected onmatch="exclude" />
  </EventFiltering>
</Sysmon>
```

Commands:
```
cd C:\Sysmon
sysmon64.exe -c sysmon-config.xml
sysmon64.exe -c
```
All correct — the last command alone (`-c` with no file) just prints the current config instead of changing it.
